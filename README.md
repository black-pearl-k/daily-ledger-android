# Daily Ledger · 每日记账

一款轻量的安卓本地记账应用。随手记录金额和用途，按北京时间整理每日消费，并将 Markdown 日报保存在手机上、通过 163 邮箱发送给自己。

## 功能

- 记录支出金额、用途和自动生成的时间；金额精确到分。
- 按日期查看明细和总支出，支持修改、删除记录。
- 每天零点后生成前一天的 `.md` 日报，保存到手机的 `下载/每日记账/`。
- 使用 163 邮箱 SMTP 发送日报附件；在后台任务获得执行机会时尝试补发遗漏的日报。
- 账目存放在手机本地 SQLite 数据库中，不需要账号或云服务器。

日报示例：

```md
# 2026-10-17 消费记录

| 金额（元） | 时间 | 用途 |
| ---: | :---: | --- |
| 18.50 | 12:30 | 午餐 |
| 6.00 | 18:42 | 地铁 |

**当日总支出：24.50 元**
```

## 安装与设置

1. 用 Android Studio 打开本项目，等待 Gradle 同步。
2. 选择 **Build → Generate App Bundles or APKs → Generate APKs**，安装生成的 `app/build/outputs/apk/debug/app-debug.apk`。也可以连接手机后直接运行 `app`。
3. 打开应用的“设置”，填写 **163 发件邮箱**、**收件邮箱**和发件邮箱的 **SMTP 授权码**。
4. 点击“测试发送”，确认收件箱收到邮件，再开始记账。

SMTP 授权码需要在 163 邮箱设置中开启 SMTP 后生成，不是邮箱登录密码。应用使用 Android Keystore 加密后在本机保存授权码；不要把授权码写进源码或提交到仓库。

## 构建

- Android Studio 与 JDK 17
- Android SDK 35
- Gradle Wrapper 已包含在项目中
- 最低支持 Android 10（API 29）

Windows 命令行：

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

## 发送与数据说明

系统后台调度和邮件服务可能延迟，所以邮件无法保证在 `00:00:00` 准时送达。日报按北京时间归属到前一天；后台任务获得执行机会时会重试未发送日报。部分手机需要允许应用后台运行；强行停止应用后，需要重新打开应用才能恢复任务。修改已发送日期的记录后，该日会重新发送一封更新版邮件。

账目数据库保存在应用私有存储中；生成的 `.md` 文件则是**明文**，位于手机下载目录，邮件附件也会经过邮箱服务。卸载应用或清除应用数据会删除本地账目，已发出的邮件和已保存的日报不会自动导回数据库。
